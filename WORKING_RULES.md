# Working rules

- Keep source, configuration, Git messages and technical documentation in English; user-facing reports in German.
- Maintain README progress, open tasks and findings.
- This is a public distribution repository. Never add private development history, credentials, personal availability or invitations.
- Publish only generic release artifacts validated against the release SHA256 manifest.
- Retain offline portability and all existing app features. No analytics or data-upload backend.
- The private publisher may update only site/index.html, site/version.json and site/.nojekyll.
- Deploy only site/ through GitHub Pages. Preserve browser-local storage and explicit file exchange.
